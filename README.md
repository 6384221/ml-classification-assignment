# X-Ray Data Warehouse Project

## Project Overview
This project loads X-ray CSV data, preprocesses it, stores it in an SQLite database,
and generates simple visualizations.

## Project Structure
- main.py
- data_loader.py
- preprocess.py
- database.py
- visualization.py
- requirements.txt

## Run the Project
Install dependencies:
    pip install -r requirements.txt

Run:
    python main.py
